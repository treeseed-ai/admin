Any verified user may create a team and becomes its first owner.

Choose a stable name for addresses and integrations. The display name, logo, profile summary, and profile visibility can be refined later in team settings.

Names must be unique and cannot use reserved platform identifiers. A rejected submission leaves the form values intact so you can correct only the affected fields.
