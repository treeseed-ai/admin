Your all-project choices are the default for every project you can access.

## Project overrides

Selecting a project creates an independent set of content choices for that project. Expand the project to choose the same content categories available in the all-project section.

An override replaces the default for that project; it does not add to it. Remove the override to return the project to your all-project choices.

Email cadence controls grouped email delivery. In-application status remains available independently.
